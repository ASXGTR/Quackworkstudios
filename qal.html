⚡ Technology Overview

Multi-Factor Physical-Presence Gating Across an Acoustic Air-Gap

Radio-frequency keyless systems are vulnerable to wireless relay attacks (RSA), signal amplification, and remote bus injection. The Quackworks Acoustic Lock (QAL) solves this vulnerability by using the physical containment of sound pressure waves inside an enclosed space (such as a vehicle cabin, secure room, or elevator) to enforce local physical presence:

FACTOR 1: PRIMARY INGRESS Standard wireless credentials (RF, BLE, or UWB) wake the system and handle initial door unlocking.
FACTOR 2: ACOUSTIC INTERLOCK Powertrain or electronic contactors remain disabled until an in-cabin, near-ultrasonic acoustic token is authenticated by interior microphones.

💡 Zero Added Hardware BOM: Purely software-defined. Reuses pre-existing hands-free cabin microphones and audio DSP processing operating at standard 44.1 kHz or 48.0 kHz sampling rates.

All code and documentation are released under the Apache License, Version 2.0. Developers, researchers, and companies are free to study, modify, adapt, or integrate this architecture into automotive, smart-building, elevator, or workstation security projects.

3. Beyond Automotive Applications

While originally prototyped as an automotive vehicle immobilizer, the core continuous-phase acoustic air-gap protocol is completely portable to elevator floor gating, apartment intercoms, server rooms, and RAT-proof computer logins.

4. Engineering Simulation Disclaimer

The code and videos represent a Software-in-the-Loop (SIL) simulation environment and architectural reference design. Series production deployment is subject to target ECU porting, transducer calibration, and vehicle-specific homologation.
